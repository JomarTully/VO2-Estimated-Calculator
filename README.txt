VO2 Calculator Web App

Estimates resting VO2 as indexed VO2 x Mosteller BSA. Includes 125, 110, and custom mL/min/m2 options.

This is an estimate, not a direct measurement. Estimated VO2 can materially affect Fick cardiac output. Follow your institution's validated protocol.

Upload index.html, manifest.json, icon-180.png, and icon-512.png to GitHub Pages, then open in Safari and Add to Home Screen.
